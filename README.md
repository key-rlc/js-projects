# JavaScript Projects 

Landing page que centraliza los proyectos de JavaScript que he desarrollado como parte del inicio de mi proceso de formación en desarrollo Full Stack.

Este repositorio funciona como un portafolio en evolución, donde aplico fundamentos de JavaScript, manipulación del DOM y buenas prácticas de frontend, como base para una formación Full Stack más completa.


## 📂 Estructura del repositorio

├── index.html          # Landing principal  
├── styles.css          # Estilos del landing  
├── script.js           # Lógica del menú interactivo  
├── 01-color-flipper/  
├── 02-counter/  
├── 03-reviews/  
├── 04-navbar/

Cada proyecto se encuentra dentro de su propia carpeta y puede ejecutarse de forma independiente.

## Proyectos incluidos

- 🎨 **Color Flipper**  
  Aplicación simple que cambia el color de fondo de forma aleatoria.  
  Conceptos: eventos, funciones, manipulación del DOM.

- 🔢 **Counter**  
  Contador con incremento y decremento de valores.  
  Conceptos: lógica condicional, manejo de estado y eventos.

- ⭐ **Reviews**  
  Componente para mostrar reseñas dinámicas.  
  Conceptos: arrays, objetos y renderizado dinámico.

*(Próximamente: Navbar, Sidebar, Modal y proyectos orientados a backend y full stack)*
